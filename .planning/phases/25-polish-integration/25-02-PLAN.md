## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-02-01 | Information Disclosure | `getWorkingDir` reading settings | accept | The function reads only the user's local settings DB. The OSPathMap keying is per-user; no network. The path is used to spawn a shell in the user's own home — already the pre-change behavior. |
| T-25-02-02 | Denial of Service (Goroutine Exhaustion) | Stress test | mitigate | The stress test asserts goroutine drift <= 5 over 100 cycles. If drift were unbounded, the test would fail and the regression would be caught in CI. The 5-goroutine delta accounts for runtime-internal goroutines (GC, sysmon) that are not under our control. |
| T-25-02-03 | Tampering | RUNBOOK.md | accept | The runbook is documentation only; no executable code. The described DOM query is read-only. |
