    - `observer.disconnect()`

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | npm packages (@xterm/*) | mitigate | All four packages verified in RESEARCH.md Package Legitimacy Audit: official xterm.js ecosystem, npm registry confirmed, no postinstall scripts. Same GH org maintainers. |
| T-17-02 | Information Disclosure | xterm.js ANSI parser | mitigate | xterm.js v6 disables OSC 52 (clipboard injection) by default. Raw PTY output rendered as display-only — no shell command execution. convertEol: true ensures consistent CR+LF handling. |
| T-17-03 | Elevation of Privilege | WebLinksAddon URL handler | mitigate | WebLinksAddon default `allowNonHttpProtocols: false` blocks `javascript:` URIs. Custom callback uses `window.open(uri, '_blank')` which delegates to browser's own origin checks. |
| T-17-04 | Elevation of Privilege | WebglAddon GPU renderer | mitigate | try/catch on `new WebglAddon()` falls back to canvas renderer on WebGL unavailability. `onContextLoss` handler disposes the addon and xterm.js auto-switches to canvas — eliminates WebGL attack surface on context loss. |
| T-17-05 | Denial of Service | xterm.js scrollback buffer | accept | `scrollback: 5000` caps memory at ~5000 lines. xterm.js uses efficient buffer management. PTY output batching (64KB chunks, 16ms tick from Phase 16 PTY-03) prevents event spam. Low-value DoS target — local desktop app. |
| T-17-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint pre-install completed in RESEARCH.md. All four packages passed — official xterm.js ecosystem. No [SLOP] or [SUS] packages remain. |
</threat_model>
