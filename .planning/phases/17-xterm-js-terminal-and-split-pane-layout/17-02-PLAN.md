## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-06 | Tampering | localStorage (terminal height/collapse) | accept | localStorage values are user-controlled by design (drag to resize). No privilege escalation possible — values are client-side UI preferences only. useResizable clamps to min/max range. Malformed stored values produce NaN which defaults to defaultSize. |
| T-17-07 | Denial of Service | Infinite re-render from useResizable | mitigate | useResizable uses `useRef` for drag tracking (not state), only calls `setSize` during mousemove. Cleanup removes event listeners on unmount. useState initializer reads localStorage once — not on every render. |
| T-17-08 | Information Disclosure | Orphaned localStorage key ('cmdex-output-height') | accept | Old OutputPane storage key remains in localStorage. Contains no secrets — just a height number (e.g., "200"). No migration needed. User can clear browser storage to remove it. |
</threat_model>
