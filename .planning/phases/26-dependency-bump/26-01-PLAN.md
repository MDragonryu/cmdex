       - Do NOT hand-edit any file under `frontend/bindings/` — they are generated output.

    3. Run `make check` which executes: `go build ./... && cd frontend && pnpm tsc --noEmit`.

       - `db_test.go` — TestFreshDBMigrations, TestExistingDBIdempotent, TestRollbackTo
       - `terminal_service_test.go` — session CRUD and cwd inheritance
       - `terminal_service_stress_test.go` — 100-cycle stress test (darwin only)
       - `terminal_service_max_sessions_test.go` — MaxSessions=10 guard (darwin only)

       - `GOOS=linux GOARCH=amd64 go build ./...`
       - `GOOS=windows GOARCH=amd64 go build ./...`
       - These are best-effort — if they fail, the error is diagnostic (e.g., conpty stub issues on Windows are known and non-blocking for this bump).
