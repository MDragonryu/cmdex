func (s *TerminalService) Write(data string) error {

    if s.ptmx == nil {

    }

}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend → Go terminalSvc.Write | User-provided variable values flow from frontend to PTY stdin via Wails IPC |
| Go → Shell PTY stdin | Resolved command text (with substituted variables) written to shell process |
| resolveWorkingDir → Shell | Stored filesystem paths (user-configured) used to construct `cd` commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Tampering | execution_service.go RunCommand cmdLine construction | mitigate | `ReplaceTemplateVars` does literal string replacement via `strings.ReplaceAll` — no shell metacharacter interpretation. Values are not re-expanded by the shell after substitution because they're written as literal bytes to PTY stdin. ASVS V5: input validated by template var regex (`\{\{(\w+)\}\}`). |
| T-18-02 | Tampering | execution_service.go cd sandwich path injection | mitigate | `shellQuoteDir` single-quote wraps the path and escapes any single quotes within it (`'\"'\"'`). If path doesn't exist, shell `cd` command fails (user-visible error in terminal) and `&&` chaining prevents command execution in wrong directory. |
| T-18-03 | Elevation of Privilege | TerminalService Write → PTY | accept | Shell runs as same user as Cmdex process. PTY process group isolation prevents cross-process tampering. No `sudo`/`runas` elevation path. Low risk for local desktop app. |
| T-18-04 | Information Disclosure | terminal output via pty-output event | accept | Terminal output rendered by xterm.js which sandboxes ANSI sequences. Output already flows via pty-output events from readLoop — no new risk introduced by this phase. |
| T-18-05 | Denial of Service | terminalSvc.Write when PTY not started | mitigate | TerminalService.Write checks `s.ptmx == nil` and returns error. RunCommand catches write error and returns ExecutionRecord with Error field. Frontend catch block shows toast. Terminal auto-restarts via monitorExit. |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase. All dependencies already present and verified in prior phases. |
</threat_model>
