  <action>
    Create `frontend/src/components/TerminalTabBar.tsx` — a new component for terminal session tabs with drag-and-drop reorder, right-click context menu, status indicators, and a '+' new-session button. Per D-01, D-02, D-03, per UI-01, UI-02.

    **Component architecture:**
    - Default export: `TerminalTabBar` — the main container component.
    - Internal sub-component: `SortableTerminalTab` — renders one tab with DnD + context menu + status dot + close button.
    - The component reuses existing `.tab-bar`, `.tab-item`, `.tab-title`, `.tab-close` CSS classes for visual consistency. Functionally it is independent — it does NOT extend or wrap the existing `TabBar` component (which has no DnD support — RESEARCH.md Assumption A1 confirmed).

    **Props interface:**
    ```typescript
    interface TerminalTabBarProps {
      sessions: SessionInfo[];
      activeSessionId: string;
      onSelectTab: (id: string) => void;
      onCloseTab: (id: string) => void;
      onReorderTabs: (sessions: SessionInfo[]) => void;
      onCreateSession: () => void;
      onRenameSession: (id: string, name: string) => void;
    }
    ```

    **@dnd-kit sensor configuration:**
    - Use `PointerSensor` with `activationConstraint: { distance: 5 }` — this prevents accidental drag initiation during click-to-select. The 5px threshold means small pointer movements (clicks) don't trigger drag.
    - Use `closestCenter` collision detection.

    **SortableTerminalTab implementation:**

    1. **DnD integration:** Call `useSortable({ id: session.id })`. Apply `setNodeRef` to the outer div. Compute inline `style` from `transform` and `transition` using `CSS.Transform.toString(transform)` from `@dnd-kit/utilities`.

    2. **Drag handle:** Place a SEPARATE drag handle element INSIDE the tab — a `<span className="tab-drag-handle" {...attributes} {...listeners}>` containing a `<GripVertical size={12} />` icon from lucide-react. Drag handle is positioned before the status dot. The drag handle receives ALL DnD `attributes` and `listeners` — the tab itself does NOT have drag listeners. This prevents Pitfall 2 (DnD/click interference) per RESEARCH.md.

    3. **Status dot:** Render `<span className={tab-status-dot ${session.running ? 'running' : 'stopped'}} />` between drag handle and tab title. Per D-01/UI-01. No "busy" state needed for this component — status derives from `session.running: boolean` only.

    4. **Tab title:** Render `<span className="tab-title" title={session.name}>{session.name}</span>` inside the tab. The title element receives the `onClick` handler for tab selection (NOT the outer div).

    5. **Close button:** Render ONLY when `!isLastTab` (where `isLastTab = sessions.length <= 1`). The close button: `<span className="tab-close" role="button" aria-label="Close ${session.name}" onClick={(e) => { e.stopPropagation(); onCloseTab(session.id); }}><X size={12} /></span>`. Per D-02 — last remaining tab is not closeable. Close button hidden (not rendered) for last tab.

    6. **Active state:** Apply `className={tab-item${isActive ? ' active' : ''}}` where `isActive = session.id === activeSessionId`.

    7. **Tab selection (click):** The tab's click-to-select is on the tab div itself (not just the title). Use `onClick={() => onSelectTab(session.id)}`. The DnD `activationConstraint: { distance: 5 }` prevents click from being mistaken for drag. Per D-04.

    8. **Context menu (right-click):** Wrap the entire tab div in shadcn `<ContextMenu>`:
       - `<ContextMenuTrigger asChild>` wraps the tab div.
       - `<ContextMenuContent>` contains two `<ContextMenuItem>` items:
         - "Rename Session" — `onSelect` opens `window.prompt('Rename session:', session.name)`. If the user enters a non-empty trimmed value, call `onRenameSession(session.id, trimmedName)`. Per D-03.
         - "Close Session" — `disabled={isLastTab}`. `onSelect` calls `onCloseTab(session.id)`. Per D-03 (grayed out for last tab).

    **TerminalTabBar (main component) implementation:**

    1. **Auto-scroll active tab into view:** Use `useRef<HTMLDivElement>` and `useEffect` (same pattern as existing TabBar.tsx lines 18-22): when `activeSessionId` changes, `activeRef.current?.scrollIntoView({ inline: 'nearest', block: 'nearest' })`.

    2. **DnD context:** Wrap the tab list in `<DndContext sensors={sensors} collisionDetection={closestCenter} onDragEnd={...}>`. Inside `onDragEnd`: get old/new indices from sessions array, call `arrayMove(sessions, oldIndex, newIndex)`, pass result to `onReorderTabs`.

    3. **SortableContext:** Wrap mapped tabs in `<SortableContext items={sessions.map(s => s.id)} strategy={horizontalListSortingStrategy}>`.

    4. **'+' button:** Render a `<div className="tab-new-session-btn" role="button" aria-label="Create new terminal session" title="New Session (Ctrl+T)" onClick={onCreateSession}>` containing a `<Plus size={14} />` icon from lucide-react. Per D-01 — '+' button always visible at the end of the tab bar. Per UI-SPEC copywriting contract: aria-label "Create new terminal session", tooltip "New Session (Ctrl+T)".

    5. **Empty state:** When `sessions.length === 0`, render nothing (return null). The parent App.tsx is responsible for ensuring at least one session exists.

    6. **Scrollbar hiding:** The outer `<div className="tab-bar">` already hides scrollbars via existing CSS (`.tab-bar::-webkit-scrollbar { display: none; }` and `scrollbar-width: none`). Per RESEARCH.md tab overflow handling.

    **Imports needed:**
    - `import { useRef, useEffect } from 'react'` (for auto-scroll)
    - `import { GripVertical, X, Plus } from 'lucide-react'` (icons)
    - `import { DndContext, closestCenter, PointerSensor, useSensor, useSensors } from '@dnd-kit/core'`
    - `import { arrayMove, SortableContext, useSortable, horizontalListSortingStrategy } from '@dnd-kit/sortable'`
    - `import { CSS } from '@dnd-kit/utilities'`
    - `import { ContextMenu, ContextMenuTrigger, ContextMenuContent, ContextMenuItem } from '@/components/ui/context-menu'`
    - `import { type SessionInfo } from '../types'`

    Do NOT import or use the `TabBar` component — TerminalTabBar is standalone. Do NOT use `@dnd-kit/react` (v2 API) — use v1 API as shown.
