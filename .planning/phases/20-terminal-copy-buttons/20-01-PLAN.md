### Copy Output button logic
```typescript
// xterm.js stores selected text internally. On click:
const handleCopyOutput = () => {
    const term = terminalRef.current;
    // xterm.js v6.0.0 has getSelection() returning the selected text
    // If nothing selected, we can select all and copy
    const sel = (term as any)?.getSelection?.() || '';
    if (sel) {
        navigator.clipboard.writeText(sel);
        toast.success(t('toast.textCopied'));
    } else {
        // Fallback: select all, copy, then clear selection
        // xterm.js has selectAll() but no clearSelection() without addon
        // Use process clipboard selection approach
        navigator.clipboard.writeText(''); // user-visible: nothing to copy
    }
};
```

**Note on Copy Output:** xterm.js v6.0.0's `Terminal` class has a `getSelection()` method that returns the currently selected text (the selection position is managed internally). No addon needed. If nothing is selected, we don't force-copy (avoids destructive selectAll behavior). The button is titled "Copy selection" to set expectations.
