### FILE 1: `terminal_unix.go` (build tag `//go:build !windows`)

Complete Unix PTY backend using creack/pty. This file provides three functions called by terminal_service.go:

1. **`ptyStartUnix(shellPath, shellFlag string, rows, cols int) (*os.File, *exec.Cmd, error)`**
   - Creates `exec.Cmd` with shellPath and shellFlag (no additional args — interactive shell)
   - Sets `cmd.Env = os.Environ()` to inherit user environment
   - Calls `pty.StartWithSize(cmd, &pty.Winsize{Rows: uint16(rows), Cols: uint16(cols)})` — this creates the PTY, sets the window size, and starts the shell process. `StartWithSize` automatically sets Setsid+Setctty (verified in research).
   - Returns `(ptmx, cmd, nil)` on success or `(nil, nil, err)` on failure
   - Imports needed: `"os"`, `"os/exec"`, `"github.com/creack/pty"`

2. **`ptyResizeUnix(ptmx *os.File, cols, rows int) error`**
   - Wraps `pty.Setsize(ptmx, &pty.Winsize{Rows: uint16(rows), Cols: uint16(cols)})`
   - Returns the error directly

3. **`killProcessGroupUnix(cmd *exec.Cmd) error`**
   - Implements D-08 graceful-then-force termination on Unix
   - Step 1: Get PID from `cmd.Process.Pid`, send `syscall.Kill(-pid, syscall.SIGHUP)`
   - Step 2: Wait up to 2 seconds for process exit using `time.After(2 * time.Second)` + `cmd.Wait()` goroutine select pattern (same as executor.go streaming pattern)
   - Step 3: If still running after 2s, send `syscall.Kill(-pid, syscall.SIGKILL)`
   - If `cmd.Process` is nil, return nil (already dead)
   - Close the PTY master BEFORE killing: call `ptmx.Close()` to unblock any pending reads (Common Pitfall 3 from RESEARCH.md — though no reader goroutine exists in this plan, this guards against future issues)
   - Imports needed: `"os"`, `"os/exec"`, `"syscall"`, `"time"`

**Package + imports:**

**Struct:**
```go
type TerminalService struct {
    mu       sync.Mutex
    ptmx     *os.File
    cmd      *exec.Cmd
    shellPath string
    shellFlag string
    lastSize  ptyWinsize  // stored as {Rows, Cols uint16}, used on restart (Pitfall 5)
    stopCh   chan struct{}
}
```
- The `ptyWinsize` type is an unexported struct: `type ptyWinsize struct { Rows uint16; Cols uint16 }` — avoids importing creack/pty directly in this file
- `stopCh` is a buffered channel of size 1 (signals goroutines to stop — used by Plan 16-02's reader/monitor goroutines)

**`detectShell() (path, flag string)` — unexported function in terminal_service.go:**
- On Windows (D-01): chain `pwsh` → `powershell` via `exec.LookPath()`. If both found, use the first (pwsh preferred). Flag: `"-NoLogo"`. If neither found, fall back to `"cmd"` with flag `""`.
- On Unix (D-02): `path = os.Getenv("SHELL")`. If empty, `path = "/bin/sh"`. Flag: `"-l"` (login shell).
- **D-07 override note:** D-07 states "Call `NewExecutor()` to get the shell path and flag — do NOT duplicate detection logic." However, D-01 requires a Windows detection chain (`pwsh` → `powershell` → `cmd`) that `NewExecutor()` does not support (executor.go:30-44 only detects `cmd` on Windows and `$SHELL` on Unix). Rather than extending `NewExecutor()` (which would change ExecutionService behavior for Phase 18 command execution), this plan creates a standalone `detectShell()` implementing the full D-01 chain. Add a comment in the code referencing both D-01 and D-07 to explain this intentional divergence.

**`ServiceStartup(ctx context.Context, options application.ServiceOptions) error`:**
- Calls `s.Start(80, 24)` with default terminal size (80 columns × 24 rows)
- Returns any error from Start. If Start fails, app startup fails (user sees error).

**`ServiceShutdown() error`** (D-09):
- Calls `s.Stop()`. Returns any error.
- Wails calls this automatically on app termination — matches App.ServiceShutdown() pattern.

**`Start(cols, rows int) error`:**
- Acquires `s.mu.Lock()` / `defer s.mu.Unlock()`
- If `s.ptmx != nil`, call `s.Stop()` first (clean up existing shell before re-spawning)
- Calls `detectShell()` to get shellPath and shellFlag
- Stores these in `s.shellPath`, `s.shellFlag`
- Stores `s.lastSize = ptyWinsize{Rows: uint16(rows), Cols: uint16(cols)}`
- Calls platform-specific `ptyStartUnix(shellPath, shellFlag, rows, cols)` or `ptyStartWindows(...)` via `if runtime.GOOS == "windows"` branch
- Stores returned ptmx and cmd in `s.ptmx` and `s.cmd`
- Creates `s.stopCh = make(chan struct{}, 1)`
- Returns nil on success

**`Stop() error`:**
- Acquires `s.mu.Lock()` / `defer s.mu.Unlock()`
- If `s.stopCh != nil`, close it: `close(s.stopCh)` (signals goroutines added in Plan 16-02)
- If `s.cmd != nil && s.ptmx != nil`, calls platform-specific kill function:
  - Unix: `killProcessGroupUnix(s.cmd)` — note: this function also closes ptmx
  - Windows: `killProcessGroupWindows(s.cmd)`
- Sets `s.ptmx = nil`, `s.cmd = nil`, `s.stopCh = nil`
- Returns nil

**`Write(data string) error`** (PTY-02 — Wails-bound):
- Acquires `s.mu.Lock()` / `defer s.mu.Unlock()`
- If `s.ptmx == nil`, return `fmt.Errorf("terminal not started")`
- Calls `s.ptmx.Write([]byte(data))`
- Returns the error (or nil)

**`Resize(cols, rows int) error`** (PTY-04 — Wails-bound):
- Acquires `s.mu.Lock()` / `defer s.mu.Unlock()`
- If `s.ptmx == nil`, return `fmt.Errorf("terminal not started")`
- Updates `s.lastSize = ptyWinsize{Rows: uint16(rows), Cols: uint16(cols)}`
- Calls platform-specific `ptyResizeUnix(s.ptmx, cols, rows)` or `ptyResizeWindows(s.ptmx, cols, rows)` via `runtime.GOOS` branch
- Returns the error (or nil)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend → TerminalService.Write | Untrusted keystroke data enters Go backend via Wails binding |
| TerminalService → Shell process | Go writes keystrokes to PTY stdin; shell interprets as user input |
| Shell process → TerminalService | Shell inherits cmdex process environment (env vars, CWD) |
| TerminalService → OS process table | Process group signal delivery (SIGHUP/SIGKILL) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering | npm/pip/cargo installs — creack/pty v1.1.24 | mitigate | slopcheck unavailable; gated behind Task 1 blocking-human checkpoint. Developer must verify at pkg.go.dev and GitHub before `go get`. |
| T-16-02 | Denial of Service | TerminalService.Write (rapid keystroke flood) | accept | PTY stdin is a byte stream; kernel buffers handle throughput. No rate limiting for Phase 16 — Write returns error if ptmx is nil (safety valve). Phase 18 may add command-length limits. |
| T-16-03 | Denial of Service | Orphaned shell processes on crash/unclean exit | mitigate | `ServiceShutdown()` (D-09) calls Stop() which performs process group kill (SIGHUP→2s→SIGKILL on Unix, taskkill /F /T on Windows). Setsid in StartWithSize makes shell a session leader — negated PID kills all children. Crash scenario: init (PID 1) reaps orphans on Unix. |
| T-16-04 | Information Disclosure | Shell inherits cmdex process environment | accept | Shell runs as the user's own process with their environment. No secrets stored in PTY output (not persisted to DB). Expected desktop app behavior. |
</threat_model>
