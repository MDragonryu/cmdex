```go
// Pattern: public method, mutex Lock for writes, return (*SessionInfo, error)
func (s *TerminalService) CreateSession() (*SessionInfo, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	s.sessionCounter++
	name := fmt.Sprintf("Terminal %d", s.sessionCounter)
	id := uuid.New().String()

	ss := &sessionState{
		id:         id,
		name:       name,
		workingDir: getWorkingDir(),  // os.UserHomeDir() fallback
		createdAt:  time.Now(),
	}

	if err := s.startSessionLocked(ss, 80, 24); err != nil {
		return nil, fmt.Errorf("CreateSession: PTY start failed: %w", err)
	}

	s.sessions[id] = ss
	if s.activeSessionID == "" {
		s.activeSessionID = id
	}

	return ss.info(), nil
}
```

**Pattern rules for CRUD methods:**
- All public methods are exported (capitalized). Return `(value, error)`.
- Mutate state under `s.mu.Lock()`. Read state under `s.mu.RLock()`.
- Use `defer s.mu.Unlock()` — keep mutex scope tight.
- Use `uuid.New().String()` from `github.com/google/uuid` for ID generation.
- Error wrapping: `fmt.Errorf("MethodName: description: %w", err)`.

#### 1f. Session Lookup Helper

**Analog:** `command_service.go` line 23-29 (`GetCategories` — uses a package-level `db` to fetch data)

```go
// Source: CONTEXT.md D-03, RESEARCH.md Pattern 5
func (s *TerminalService) getSession(sessionId string) (*sessionState, error) {
	if sessionId == "" {
		s.mu.RLock()
		sessionId = s.activeSessionID
		s.mu.RUnlock()
		if sessionId == "" {
			return nil, fmt.Errorf("no active session")
		}
	}
	s.mu.RLock()
	ss, ok := s.sessions[sessionId]
	s.mu.RUnlock()
	if !ok {
		return nil, fmt.Errorf("session not found: %s", sessionId)
	}
	return ss, nil
}
```

**Gotcha:** Do NOT hold `s.mu.RLock()` while operating on `ss`. The `ss` has its own `sync.Mutex`. Snapshot the pointer under read-lock, release, then use the pointer.

#### 1g. Write/Resize/Clear/Start/Stop — Method Dispatch Pattern

**Analog:** `terminal_service.go` lines 339-362 (`Write` — existing method, add sessionId parameter)

```go
// Source: terminal_service.go lines 339-362 (existing Write, adapted with sessionId dispatch)
func (s *TerminalService) Write(sessionId string, data string) error {
	ss, err := s.resolveSession(sessionId)
	if err != nil {
		return err
	}

	ss.mu.Lock()
	defer ss.mu.Unlock()

	if !ss.running {
		if err := s.startSessionLocked(ss, int(ss.lastSize.Cols), int(ss.lastSize.Rows)); err != nil {
			return err
		}
	}

	if ss.ptmx == nil {
		return fmt.Errorf("terminal not started")
	}

	b := []byte(data)
	for len(b) > 0 {
		n, err := ss.ptmx.Write(b)
		if err != nil {
			return err
		}
		b = b[n:]
	}
	return nil
}
```

**Pattern rule:** All existing public methods (`Write`, `Resize`, `Clear`, `Start`, `Stop`) gain a `sessionId string` as the first parameter. They look up the session, then delegate to the wrapper or the session's own method. If `sessionId` is `""`, fall back to `activeSessionID`.

#### 1h. PTY Start with Unlock-Before-Blocking Pattern

**Analog:** `terminal_service.go` lines 248-305 (`startLocked` — MUST preserve unlock-before-close)

```go
// Source: terminal_service.go lines 269-284 (critical unlock-before-blocking pattern)
// MUST NOT refactor away the s.mu.Unlock() at line 271.
// It prevents deadlock: closing old PTY fd blocks until readLoop exits,
// and readLoop may contend on the mutex.

	s.mu.Unlock()        // <-- CRITICAL: release before blocking operations

	if oldPtmx != nil {
		oldPtmx.Close()           // blocking — reader fd close
	}
	if oldCmd != nil {
		killProcessGroup(oldCmd)  // blocking — waits for process to die
	}

	s.readerWg.Wait()            // blocking — waits for reader goroutine exit

	// ... then create new PTY ...

	s.mu.Lock()                  // re-acquire after blocking ops
```

**When adapting to per-session:** The session-level `ss.mu.Unlock()` must be called before any PTY close, `killProcessGroup`, or `readerWg.Wait()`. Then `ss.mu.Lock()` after.

#### 1k. Service Shutdown (Closes All Sessions)

**Analog:** `terminal_service.go` lines 235-239

```go
// Source: terminal_service.go lines 235-239 (existing shutdown, adapted for multi-session)
func (s *TerminalService) ServiceShutdown() error {
	s.mu.Lock()
	sessionIDs := make([]string, 0, len(s.sessions))
	for id := range s.sessions {
		sessionIDs = append(sessionIDs, id)
	}
	s.mu.Unlock()

	for _, id := range sessionIDs {
		s.CloseSession(id)  // calls ss.Stop() internally
	}
	return nil
}
```

**Gotcha:** Snapshot IDs under lock, release lock, THEN iterate. Do NOT hold `s.mu` while calling `CloseSession` (which acquires its own locks and blocks on PTY close).

#### 1l. `monitorExit` — Per-Session Exit Handling

**Analog:** `terminal_service.go` lines 180-223

```go
// Source: terminal_service.go lines 180-223 (existing monitorExit, adapted per-session)
// Key changes:
//  - Receiver is sessionState, not TerminalService
//  - Check ss.stopCh instead of shared channel
//  - Event emission uses "pty-exit:" + ss.id
//  - Auto-restart calls ss.startLocked (session-level)
func (ss *sessionState) monitorExit(cmd *exec.Cmd, ptmx *os.File, stopCh chan struct{}) {
	err := cmd.Wait()

	select {
	case <-stopCh:
		return
	default:
	}

	exitCode := 0
	if err != nil {
		if exitErr, ok := err.(*exec.ExitError); ok {
			exitCode = exitErr.ExitCode()
		} else {
			exitCode = -1
		}
	}

	ss.mu.Lock()
	intentional := ss.intentionalStop || exitCode == 0
	cols := int(ss.lastSize.Cols)
	rows := int(ss.lastSize.Rows)
	ss.mu.Unlock()

	if wailsApp != nil {
		wailsApp.Event.Emit("pty-exit:"+ss.id, map[string]interface{}{
			"exitCode":       exitCode,
			"wasIntentional": intentional,
		})
	}

	// ... rest of exit/restart logic unchanged ...
}
```

**Pattern rules for tests:**
- All helpers use `t.Helper()` for correct line attribution on failure.
- `t.Fatalf` for setup failures, `t.Errorf` for assertion failures.
- Use `t.Cleanup` for resource cleanup, not `defer` — it runs even if the test panics.
- Use `testing.Short()` to skip integration tests: `if testing.Short() { t.Skip("skipping integration test in short mode") }`.
- **Race detector is mandatory:** Always run with `-race` flag: `go test -race -count=1 -run 'TestTerminal' -v ./...`.
