    Per D-01, D-02, D-03, D-06, D-07 from CONTEXT.md. Implement the following methods on `*TerminalService`:

    1. **`CreateSession() (*SessionInfo, error)`**:
       - Lock `s.mu`, defer unlock.
       - Increment `s.sessionCounter` (starts at 0, first call makes it 1).
       - Set `name` to `fmt.Sprintf("Terminal %d", s.sessionCounter)`.
       - `id := uuid.New().String()`.
       - Create `sessionState{id, name, ...}` — set `workingDir` via `getWorkingDir()`, set `createdAt` to `time.Now()`, set `lastSize` to `ptyWinsize{Rows: 24, Cols: 80}`.
       - Insert into `s.sessions[id] = ss`.
       - If `s.activeSessionID == ""`, set `s.activeSessionID = id` (first session auto-active).
       - Return `ss.info(), nil`.
       - NOTE: Do NOT call `startSessionLocked` yet — that belongs to Plan 02. The session is created in stopped state. Plan 02 Task 1 will add the PTY start call.

    2. **`ListSessions() []*SessionInfo`**:
       - RLock `s.mu`, defer RUnlock.
       - Iterate `s.sessions`, call `.info()` on each, collect into slice.
       - Return slice (empty if no sessions).

    3. **`CloseSession(id string) error`**:
       - Lock `s.mu`.
       - Look up session in map. Return error if not found.
       - Delete from map: `delete(s.sessions, id)`.
       - If `s.activeSessionID == id`: pick another session (iterate map, set to first found), or `""` if map empty.
       - Unlock `s.mu`.
       - Per D-07: CloseSession always succeeds (no error return for the close itself). Only error is "session not found".
       - NOTE: PTY cleanup (Stop) is a stub placeholder for now. Add a `// TODO(Plan 02): call ss.stopSession() to kill PTY and wait for goroutines` comment. Plan 02 Task 1 will add the actual cleanup.

    4. **`RenameSession(id string, name string) error`**:
       - Lock `s.mu`, defer unlock.
       - If `name == ""`, return `fmt.Errorf("RenameSession: name cannot be empty")` per D-07.
       - Look up session. Return `fmt.Errorf("RenameSession: session not found: %s", id)` if missing.
       - Set `ss.name = name`.
       - Return nil.

    5. **`SetActiveSession(id string) error`**:
       - Lock `s.mu`, defer unlock.
       - Verify session exists in `s.sessions`. Return `fmt.Errorf("SetActiveSession: session not found: %s", id)` if not.
       - Set `s.activeSessionID = id`.
       - Return nil.

    6. **`GetActiveSession() *SessionInfo`**:
       - RLock `s.mu`, defer RUnlock.
       - If `s.activeSessionID == ""`, return nil.
       - Look up and return `ss.info()`; return nil if not found (race-safe).

    Delete the following methods that are now replaced or will be rewritten in Plan 02:
    - Remove `Start()`, `Stop()`, `Write()`, `Resize()`, `Clear()` old method bodies (keep as stubs or remove — Plan 02 adds sessionId-parameter versions)
    - Remove `startLocked()`, `stopLocked()` — Plan 02 reimplements as per-session methods
    - Remove `startEmitter()`, `stopEmitter()`, `enqueueOutput()` — Plan 02 reimplements as per-session methods
    - Remove `readLoop()`, `monitorExit()` — Plan 02 reimplements as per-session methods
    - Keep `detectShell()` as-is (unchanged standalone function)

    After removing old methods, the file should compile clean: `go build ./...` passes (no references to removed fields/methods from remaining code).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Tampering | RenameSession name parameter | mitigate | Reject empty string at method entry (`name == ""` returns error). Non-empty name is benign input (display label only — not used in shell commands or file paths). |
| T-21-02 | Denial of Service | CloseSession cleanup | mitigate | Plan 02 Task 1 will add PTY process kill + goroutine WaitGroup.Wait(). Plan 02 Task 2 will add ServiceShutdown iteration over all sessions. Currently: CloseSession has a TODO placeholder. |
| T-21-03 | Information Disclosure | Session ID enumeration | accept | UUID v4 is not enumerable (122 bits of randomness). Session IDs are only visible to frontend (same process). No external exposure. |
| T-21-04 | Denial of Service | Concurrent map access race | mitigate | All session map access uses `s.mu.Lock()` for writes, `s.mu.RLock()` for reads. `go test -race` in Plan 03 verifies. |
